Questline — app design

An achievement tracker that turns any big goal into a quest line. iOS and Android, phone, portrait. This package holds the design system, every screen and state, and a clickable prototype — built from shared, accessible components with realistic example data that follows the backend’s rules.

Approved direction

Design system

Colour (light and dark, every contrast pair checked), type, spacing, radius, elevation, icons, motion and all components in every state.

How to review
