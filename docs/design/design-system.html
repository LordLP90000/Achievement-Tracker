Design system

A quest log that feels like a calm, modern productivity app: warm sand neutrals, one honey accent, rounded cards and quiet depth. Tokens live in tokens.json (source of truth; tools/tokens.mjs generates the CSS and checks every contrast pair), components in assets/js/ui.js. Use the toolbar to view every specimen at 150 % / 200 % text, on Android, or with reduced motion.
